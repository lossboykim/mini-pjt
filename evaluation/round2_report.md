## 측정 후 변경
위 고정 16건과 RAGAS 측정(`2eb17fe`) 뒤에 화면 확인과 정식 평가의 지적에서 찾은 세 가지를 고쳤다. 되묻는 답의 문구만 바뀌고 판단 규칙은 같다.
- 번호 표기: 화면 마크다운이 "1." "1."로 다시 세던 것을 ①②로 바꿨다.
- 관련 없는 과거 장애: 서비스 이름 줄 때문에 걸러지지 않던 TLS 인증서 건(502 질문)을 증상·원인 기준으로 제외했다.
- DB 묶음에 섞이던 게이트웨이 장애: DB 타임아웃 질문의 되묻는 답에 게이트웨이 504 건(INC-1004)이 들어갔다(증상 단서 `타임아웃`이 서비스를 가리지 않음). 정식 평가가 구분 평가 D04 결과에서 지적했고, 묶음별 `incident_cues`를 두어 DB 묶음에는 DB 전용 단서를 지정했다. 실제 장애 이력 DB로 세 묶음의 표시·제외 장애를 검사하는 테스트를 추가했다.

이 변경 뒤 구분 평가 12건은 깨끗한 커밋 `2ece47c`에서 전부 다시 측정해 12/12였고, 결과 파일이 현재 코드의 답을 담는다. 고정 16건과 RAGAS는 다시 재지 않았다. 고정 16건 중 이 문구에 영향받는 P02는 변경 후 다시 돌려 통과했다(DB 묶음 변경은 P02가 속한 게이트웨이 묶음과 무관).
