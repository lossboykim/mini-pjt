- 평가 3회 모두 측정 중에 us-east-1의 Sonnet 4.5가 일일 한도에 걸렸다. us-west-2의 같은 모델로 넘어가 끝까지 쟀다(실행 중 대체).
  - run1: 16:54:58 한도 → 16:54:59 us-west-2
  - run2: 16:56:07 → 16:56:09
  - run3: 16:56:02 → 16:56:04
- RAGAS 산출 1·2회는 시작 전 확인에서 us-east-1이 한도라는 것을 알고 처음부터 us-west-2를 골랐다(실행 전 확인, `probe:daily_quota`). 3회는 실행 중에 넘어갔다.
- 감독자(Haiku 4.5, us-east-1)는 대체 없이 끝까지 썼다.
- 일일 한도 대체의 두 단계(실행 전 확인, 실행 중 대체)가 모두 실제로 동작했다. 대체 모델이 설정 모델과 같은 Sonnet 4.5라서 이전 라운드와 비교할 수 있다.
