# RB-06 DB 연결 타임아웃: DB 페일오버 진행 중

- 대상 서비스: DB를 쓰는 모든 애플리케이션
- 증상 키워드: DB 연결 타임아웃, connection timeout, 연결 오류, 페일오버

## 증상
- 여러 서비스에서 동시에 DB 연결 타임아웃과 `connection refused`가 난다.
- DB 프라이머리가 교체되는 중이거나 읽기 전용 상태 알림이 함께 온다.

## 진단 절차
1. DB 클러스터 상태에서 현재 프라이머리와 페일오버 시작 시각을 확인한다.
2. 앱이 바라보는 DB 엔드포인트가 새 프라이머리로 갱신됐는지 확인한다.
3. 복제 지연(replication lag)이 줄어드는지 본다.

## 조치 절차
1. 페일오버가 끝날 때까지(보통 2분 이내) 앱 풀 설정은 바꾸지 않고 기다린다.
2. 완료 후에도 연결이 안 되는 앱은 DNS 캐시 갱신을 위해 해당 앱의 롤링 재시작을 담당자에게 요청한다.
3. 정상화 후 쓰기 요청의 성공률을 확인한다.

## 주의
- 풀 크기를 늘리는 조치는 페일오버 중에는 효과가 없고 DB 부하만 키운다.
