# RB-10 에러율 급증: 최근 배포가 원인일 때

- 대상 서비스: payment-api 등 API 서비스
- 증상 키워드: 에러율 상승, 5xx 증가, 배포 직후 장애

## 증상
- 에러율이 평소의 몇 배로 올랐고 시작 시점이 최근 배포와 가깝다.

## 진단 절차
1. `kubectl rollout history deployment/<name>`으로 최근 배포 시각을 확인한다.
2. 에러율이 오르기 시작한 시각과 배포 시각을 비교한다.
3. 에러 로그의 상위 메시지를 확인한다.

## 조치 절차
1. 배포 시각과 에러 증가 시점이 일치하면 `kubectl rollout undo deployment/<name>`로 롤백을 요청한다.
2. 롤백 후 에러율이 5분 안에 평소 수준으로 돌아오는지 확인한다.
3. 배포와 무관하면 의존 서비스(DB, 외부 API) 상태를 먼저 확인한다.

## 주의
- 롤백은 서비스 담당자 확인 후 실행한다.
